# 🚀 Projetos de Análise e Desenvolvimento de Sistemas (Python)

Bem-vindo(a) ao meu repositório de estudos e práticas em **Python**! Este espaço foi criado para armazenar, organizar e acompanhar a minha evolução na programação durante a minha jornada na faculdade de Análise e Desenvolvimento de Sistemas (ADS).

---

## 📂 Conteúdo do Repositório

Atualmente, o repositório conta com os seguintes scripts e exercícios práticos iniciais:

* **`calculo_de_media.py`**: Script desenvolvido para calcular a média de notas de forma automatizada.
* **`exercicio_def_foo.py`**: Prática focada na criação e reutilização de funções (`def`).
* **`exercicio_input.py`**: Exercício focado na captura e tratamento de dados inseridos pelo usuário via terminal (`input`).
* **`exercicio_logica_ou_semantica.py`**: Atividades voltadas para o fortalecimento da lógica de programação.
* **`meu_primeiro_programa_em_python.py`**: O meu ponto de partida no universo Python.
* **`script.py`**: Arquivo de testes e experimentações gerais.
